# hypotenuse Finder
## Description
It finds the hypotenuse of 2 lengths
## How to Run
Open the file, then it runs.
## You need X values for 1 and 2, same for Y.
List the values that the user needs to enter.
## Sample Output
using the formula, math.sqrt(a*a+b*b)/2 .
